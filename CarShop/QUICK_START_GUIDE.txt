🚀 GETTING STARTED (5 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Start the Application
  • Press F5 in Visual Studio
  • Or: Debug → Start Debugging
  • Browser opens to http://localhost:port/Default.aspx
  • Automatically redirects to Home.aspx

Step 2: Populate Database with Sample Cars
  • Navigate to: http://localhost:port/Setup.aspx
  • Page automatically inserts 15 sample cars
  • See: "✓ הצליח! נוספו X רכבים לבסיס הנתונים" (Success message)
  • Click "חזור לדף הבית" (Back to Home)

Step 3: Browse the Car Catalog
  • Click "לקטלוג הרכבים" (To Catalog) button
  • Or navigate to: Cars.aspx
  • See all 15 cars displayed in cards
  • Try search and category filtering

Step 4: Test Registration
  • Click "הרשמה" (Register) in menu
  • Fill in form with test user data
  • Example:
	- Username: testuser
	- Email: test@example.com
	- Password: 123456
  • Click "הירשם" (Register)
  • Redirects to login page

Step 5: Login
  • Use credentials you just created
  • Click "התחברות" (Login)
  • Now logged in as regular user

Problem: No cars showing on Cars.aspx
  Solution: Visit Setup.aspx first to populate database

Problem: "Database connection error"
  Solution: 
  • Ensure (LocalDB)\MSSQLLocalDB is running
  • Check connection string in Web.config
  • Verify CarShopDB.mdf exists in App_Data

Problem: Registration fails
  Solution:
  • Make sure password is at least 6 characters
  • Email must contain @
  • Username must be at least 3 characters
  • No duplicate usernames/emails

Problem: Can't access Admin pages
  Solution:
  • Only admins (IsAdmin = 1) can access
  • Create admin user manually via SQL if needed
