PROBLEM:
--------
Parser Error: The file '/Home.aspx.cs' does not exist.

ROOT CAUSE:
-----------

recreated (Home.aspx, Cars.aspx, Admin.aspx, Register.aspx) but their
corresponding code-behind files (.cs) and designer files (.designer.cs)
were NOT created. This caused the ASP.NET parser to fail because it 
couldn't find the required code-behind classes.
