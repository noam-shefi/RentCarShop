ASP.NET Parser Requirement:
  If an ASPX page has:  <%@ Page ... CodeFile="Home.aspx.cs" Inherits="Home" %>
  Then it MUST have:   public partial class Home : System.Web.UI.Page { }

When the parser loads the page and can't find the code-behind class, 
it throws: "Parser Error - The file does not exist"
